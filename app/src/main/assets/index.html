Rekordbox Doctor

Checks and repairs the library rekordbox exports to a USB stick, the export.pdb CDJs and XDJs read.

The repair engine is rekordbox-usb-repair by themisterchong, MIT licensed. It rebuilds the file from every row that can still be read and puts long strings on a 4-byte boundary, which XDJ-700 and CDJ-2000NXS2 need.
